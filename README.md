# 🛒 GoShopper – E-commerce Platform

![GoShopper Banner](https://imgur.com/your-banner-link.png) <!-- Optional: Replace with your own banner image URL -->

GoShopper is a feature-rich e-commerce web application built with **.NET Core** and **Razor Pages**, designed to provide a seamless online shopping experience for users and a flexible management interface for administrators.

---

## 🚀 Features

- ✅ **User Authentication & Authorization**
  - Login with Google, Facebook, or custom credentials
  - Role-based access (Admin, User)

- 💳 **Payment Integration**
  - Secure and seamless payment gateway integration

- 📩 **Email Notifications**
  - Email confirmations for orders and account activities

- 🛍️ **Product & Cart Management**
  - Add to cart, update quantity, remove items
  - View product listings with details

- 👨‍💼 **Admin Dashboard**
  - Manage products, users, and orders

- 🔐 **Session Management**
  - Maintains user activity securely throughout sessions

---

## 🛠️ Tech Stack

| Tech | Description |
|------|-------------|
| **Backend** | .NET Core, C# |
| **Frontend** | Razor Pages, Bootstrap |
| **Database** | SQL Server |
| **ORM** | Entity Framework Core |
| **Authentication** | ASP.NET Identity Framework |
| **Others** | Google OAuth, Facebook Login, SMTP Email |
